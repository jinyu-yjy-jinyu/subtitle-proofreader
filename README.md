# SubtitleProofreader · 字幕校对

左边播放视频，右边显示字幕文本，**按视频当前播放秒数高亮对应的那一句**，并支持直接修改文字、导出修正后的字幕。

零安装、零依赖：只需 Node.js 18+，双击 `start-web.bat` 即用。

```
┌──────────────────────────────────────────────────────────────┐
│ [打开视频] [打开字幕] | [下载字幕]      sample.srt ● [跟随中] │
├────────────────────────────────┬─────────────────────────────┤
│                                │  00:00  嗨，大家好，我是谨羽。│
│         <video>                │▶ 00:01  今天我们来做字幕校对。│
│                                │  00:02  左边是视频，右边是文本│
│                                │  00:05  播放的时候，对应的字幕… │
│ [▶] [⏮][⏭] 00:01/00:34 ────  1x│                             │
├────────────────────────────────┴─────────────────────────────┤
│ 10 条 · 0 错误 · 1 警告                      00:01 / 00:34   │
└──────────────────────────────────────────────────────────────┘
```

## 功能

| 能力 | 说明 |
| --- | --- |
| 按秒数高亮 | 播放时自动定位当前时间区间内的字幕；重叠字幕同时高亮 |
| 先校验后使用 | 打开字幕先做格式校验（时间码、序号、重叠、空行、越界），有问题弹出逐条明细 |
| 点击跳转 | 点击任意一句，视频跳到该句开头 |
| 双击编辑 | 行内编辑；`Ctrl+Enter` 提交、`Esc` 取消、`Tab` 跳下一句 |
| 删除即清空 | 把某句文字清空，导出时该句被删除并重新连续编号 |
| 导出 SRT / TXT | 导出修正后的字幕，保留原文件的换行风格（CRLF/LF） |
| 纯文本兜底 | 无时间轴的 `.txt` 按字数占比映射到视频时长，可用「每秒字数」滑块微调 |
| 大文件不卡 | 虚拟滚动，2000 条字幕只渲染可视区的十几行 |
| 编码兼容 | UTF-8 / UTF-8-BOM / UTF-16 / CRLF 均可正确处理 |

## 快速开始

### Windows

双击 **`start-web.bat`**，浏览器会自动打开 <http://127.0.0.1:5178/>。

### 任意平台

```bash
node scripts/serve-web.js
```

然后点「打开字幕」选择 `.srt`，点「打开视频」选择视频即可开始校对。

> 需要 Node.js 18 或更高版本。程序**零运行时依赖**，不需要 `npm install`。

## 用法

1. **打开字幕**（`Ctrl+Shift+O`）——支持 `.srt` / `.ass` / `.txt`
2. **打开视频**（`Ctrl+O`）——支持浏览器能播的格式
3. 播放 → 右侧自动高亮当前句 → **双击**修改文字
4. 点「下载字幕」保存修正结果

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `Ctrl+O` / `Ctrl+Shift+O` | 打开视频 / 字幕 |
| `Ctrl+S` | 下载字幕 |
| `Alt+←` `Alt+→` | 后退 / 前进 1 秒 |

## 格式校验规则

打开字幕时先校验，状态栏显示汇总，点「查看校验详情」看逐条说明：

- **错误**：时间码无法解析、结束时间不晚于开始时间
- **警告**：序号重复、缺少序号行、时间轴回退、相邻字幕重叠、文本为空、结束时间超出视频时长
- **提示**：未检测到时间轴（按纯文本处理）

## 已知限制

- **视频格式**：浏览器原生只支持 mp4 / webm 等。mkv / avi / mov / wmv 需先转换：

  ```bash
  ffmpeg -i input.mkv -c:v libx264 -c:a aac output.mp4
  ```

- **编码**：浏览器 `File.text()` 只认 UTF-8，GBK/GB18030 编码的字幕会乱码，需另存为 UTF-8。
- **时间码**：v1 不支持在界面里修改时间轴，只能改文字。

### 工程结构

```
web/                     前端（原生 HTML/CSS/ESM，无框架无打包器）
├─ index.html            界面骨架
├─ app-web.js            主控制器：打开/编辑/保存/时间同步
├─ core/                 纯函数，浏览器无关，可单独测试
│  ├─ srt-parser.js      SRT/ASS/纯文本解析 + 格式校验
│  ├─ timing.js          时间轴推算 + 二分定位当前句
│  └─ srt-writer.js      SRT / TXT 序列化
├─ ui/
│  ├─ cue-list.js        虚拟滚动列表 + 行内编辑
│  ├─ player-web.js      播放器封装（逐帧同步）
│  └─ toast-web.js       轻提示与模态框
└─ styles.css

scripts/
├─ serve-web.js          本地静态服务（含 Range 与目录穿越防护）
└─ check-web.js          端点与安全检查

test/                    node:test 单元测试
example/sample.srt       示例字幕（10 条 / 35 秒）
```

`core/` 与 `ui/` 不依赖任何浏览器 API 或框架，因此可以脱离界面单独测试——这也是测试能覆盖解析、时间定位、序列化等核心逻辑的原因。
